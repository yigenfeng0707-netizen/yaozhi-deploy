# 窑智 · 陶瓷工艺 AI 大脑

面向钧瓷等传统优势产业的"釉面质检 — 缺陷归因 — 烧成寻优"一体化闭环演示系统。

- **釉面质检**：PatchCore 轻量化无监督检测（ResNet18 中层特征 + coreset 记忆库），覆盖釉泡、针孔、裂纹、落渣、色差五类典型缺陷，单张推理约 0.2s（CPU）。
- **窑温数字孪生**：一维瞬态热传导隐式差分求解坯体温度场，内置 573℃ 石英晶型转变判据，支持 108 组参数网格寻优。
- **纹样生成**：参数化生成冰裂纹、缠枝纹、回纹、泼釉等传统纹样并做可制造性校验。

## 使用

- 打开页面即可体验 **一键闭环演示**（检测 → 窑位归因 → 参数寻优 → 首件复检，约 14 秒，界面明确标注仿真数据口径）。
- 也可在"釉面质检"页上传釉面图片体验检测，或使用页面内置样本。

## 技术栈

Python 3.10 · PyTorch (CPU) · FastAPI · OpenCV · 原生 JS 前端
